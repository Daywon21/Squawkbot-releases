# SquawkBot

Desktop streaming assistant for **Twitch**, **YouTube**, **Kick**, and **OBS** on Windows.

## Download

| Installer | Description |
|-----------|-------------|
| **[SquawkBot-Setup.exe](https://github.com/Daywon21/Squawkbot-releases/releases/latest)** | Windows installer (recommended; in-app updater uses this) |
| **[SquawkBot.exe](https://github.com/Daywon21/Squawkbot-releases/releases/latest)** | Portable — run directly, no install |

**Requirements:** Windows 10/11 (64-bit), [OBS Studio](https://obsproject.com) with WebSocket server enabled (default port 4455)

## Quick start

1. Download and run **SquawkBot-Setup.exe** (or use portable **SquawkBot.exe**).
2. In OBS → **Tools → WebSocket Server Settings**, enable the server (port **4455**, set a password).
3. In SquawkBot → **Settings → OBS**, enter host `127.0.0.1`, port, and password.
4. Log in to Twitch (broadcaster + bot accounts) and other platforms as needed.
5. Click **Hoist the Sails!**

## Verify download (optional)

Compare SHA256 hashes listed on each [Release](https://github.com/Daywon21/Squawkbot-releases/releases) page.

## Updates

SquawkBot checks this repository for new **SquawkBot-Setup.exe** releases. Use **Settings → Updates → Check for Updates** or leave auto-check enabled on startup.
